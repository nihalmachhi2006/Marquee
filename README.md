# Marquee

Personal learning projects

## Repository structure

- `learning/` — HTML, CSS, JavaScript, and interview-question practice.
- `data/` — resume PDFs, supporting documents, and study resources.

Each web project keeps its HTML, stylesheets, and assets together so it can be opened independently in a browser.

## Learning areas

- `learning/html/` — HTML exercises organised by topic.
- `learning/css/fundamentals/` — focused CSS exercises.
- `learning/css/projects/` — standalone CSS projects and clones.
- `learning/javascript/` — JavaScript practice files.
- `learning/interview-questions/` — interview preparation notes.
